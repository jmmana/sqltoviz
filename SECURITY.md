# Security policy / Política de seguridad

## English

Report a suspected vulnerability using **Report a vulnerability** on the repository’s [Security page](https://github.com/jmmana/sqltoviz/security). If private reporting is unavailable, contact the repository maintainer privately and ask for a secure reporting channel before sharing details.

Include the affected package or site, version or commit, impact, and minimal reproduction using synthetic data. Keep credentials, customer data and vulnerability details out of public issues and pull requests. Coordinate public disclosure with the maintainers.

## Español

Reporta una posible vulnerabilidad mediante **Report a vulnerability** en la [página de seguridad](https://github.com/jmmana/sqltoviz/security) del repositorio. Si el reporte privado no está disponible, contacta en privado al responsable del repositorio y pide un canal seguro antes de compartir detalles.

Incluye el paquete o sitio afectado, la versión o commit, el impacto y un caso mínimo reproducible con datos sintéticos. Mantén las credenciales, los datos de clientes y los detalles de la vulnerabilidad fuera de los issues y PR públicos. Coordina la divulgación con los responsables del repositorio.
